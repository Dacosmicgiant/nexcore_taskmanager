# Task Manager Application

A fully functional task management application built with React and TypeScript, featuring a clean user interface and comprehensive task organization capabilities.

## Features

- Create, edit, and delete tasks with title, description, due date, and priority levels
- Mark tasks as complete/incomplete
- Advanced filtering by status (all/active/completed) and priority (low/medium/high)
- Real-time search functionality
- Drag-and-drop task reordering
- Persistent storage using browser localStorage
- Responsive design for mobile and desktop

## Tech Stack

- React 19 with TypeScript
- Vite for build tooling
- Tailwind CSS for styling
- GitHub Actions for CI/CD

## Installation

```bash
npm install
npm run dev
```

The application will be available at `http://localhost:5173`

## Deployment

Automatically deployed to GitHub Pages via GitHub Actions on every push to main branch.
